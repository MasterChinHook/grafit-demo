# grafit-demo

Сайт для компьютерного клуба Grafit в Белгороде (пр. Богдана Хмельницкого, 62а).
Пока это демо-версия, поисковики его не индексируют.

Живая версия: https://masterchinhook.github.io/grafit-demo/

Стек: Vite, Three.js для 3D на первом экране, GSAP для анимаций при скролле. Бэкенда нет, сайт полностью статичный.

## Запуск

```bash
npm install
npm run dev
```

Собрать: `npm run build`. Выложить на GitHub Pages: `npm run deploy`.
Скрипт сам соберёт проект и запушит сборку в ветку `gh-pages`, сайт обновится через минуту-две.

## Как поменять контент

Цены, список «Почему Grafit», телефон, ВК и ссылка на 2ГИС лежат в `src/content.js`.
Прайс и кнопки в форме брони строятся из этого файла, поэтому цену достаточно поменять в одном месте.

Заголовок первого экрана, заголовки секций и мета-теги находятся в `index.html`.
Цвета заданы переменными в начале `src/style.css`, основной акцент — `--accent`.

Фото зала кидаются в `public/photos/` (jpg, webp или png). Галерея подхватит все файлы сама, в порядке имён: 01.jpg, 02.jpg и так далее.
Лучше заранее ужать их примерно до 1600 px по длинной стороне. Пока папка пустая, в галерее стоят заглушки.

Картинка для превью в соцсетях — `public/og.jpg`, 1200×630.

Если сайт переедет на свой домен, собирайте с `BASE_PATH=/` (подробности в `vite.config.js`).

## Бронь

Форма ничего никуда не отправляет. Она собирает текст заявки (имя, дата, время, сколько часов), копирует его в буфер обмена и предлагает позвонить или написать в сообщество ВК.
