# Grafit — демо-сайт компьютерного клуба

Статичный сайт-пример для компьютерного клуба Grafit (Белгород): Vite + Three.js + GSAP.
Это демо: в `<head>` стоит `robots: noindex`, в футере есть плашка «Демо-версия».

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173/grafit-demo/
npm run build      # сборка в dist/
npm run preview    # просмотр сборки: http://localhost:4173/grafit-demo/
npm run shots      # скриншоты и проверка консоли в Playwright (нужен запущенный preview)
npm run deploy     # собрать и опубликовать на GitHub Pages вручную
```

Сайт: https://masterchinhook.github.io/grafit-demo/

Сайт публикуется из ветки `gh-pages`. Обновить его можно двумя способами:

- **Автоматически:** push в `main` запускает GitHub Actions (`.github/workflows/deploy.yml`). Workflow собирает сайт и кладёт сборку в `gh-pages`.
- **Вручную:** `npm run deploy` делает то же самое с вашего компьютера. Нужен, пока Actions на аккаунте не работают: на 21.09.2026 они заблокированы из-за проблемы с оплатой.

## Что где менять

| Что | Где |
| --- | --- |
| **Цены** (часы, сумма, подпись) | `src/content.js` → `prices`. Карточки прайса и кнопки в форме брони обновятся сами |
| Пометка «Цены по данным 2ГИС» | `src/content.js` → `pricesSource` |
| Блок «Почему Grafit» | `src/content.js` → `reasons` |
| Телефон, ВК, адрес, ссылка на 2ГИС | `src/content.js` → `club`, а также ссылки `tel:` и `vk.com` в `index.html` |
| Заголовок и тексты первого экрана, заголовки секций | `index.html` |
| Title, description, og-теги | `index.html` → `<head>` |
| Цвета и шрифты | `src/style.css` → блок `:root` |
| 3D-сцена | `src/scene.js` |
| Картинка для соцсетей | `public/og.jpg` (1200×630) |

### Фото

Положите любые `.jpg`, `.jpeg`, `.webp` (а ещё `.png` или `.avif`) в `public/photos/` и пересоберите сайт или сделайте push.
Галерея покажет их все в алфавитном порядке (`01.jpg`, `02.jpg`…). Пока папка пустая, на их месте стоят заглушки.
Фото стоит заранее ужать до 1600 px по длинной стороне, примерно 200–300 КБ на файл.

### Base-путь

Сайт собирается под адрес `https://<user>.github.io/grafit-demo/`. Base-путь задаётся в `vite.config.js`
(переменная `BASE_PATH`, по умолчанию `/grafit-demo/`). Для собственного домена соберите с `BASE_PATH=/`.

## Техника

- 3D грузится отдельным чанком: заголовок появляется сразу, сцена подгружается следом.
- `pixelRatio` не выше 2. Если кадры тормозят, он снижается автоматически. Сцена не рендерится, когда первый экран не виден или вкладка неактивна.
- Без WebGL вместо сцены показываются CSS-шестигранники. При `prefers-reduced-motion` сцена статична, скролл-анимации выключены.
- Шрифт Unbounded подключён локально через `@fontsource-variable`, внешних CDN нет.
- Форма брони работает без бэкенда: собирает текст заявки, копирует его в буфер и даёт кнопки «Позвонить» и «Написать в ВК».
